# User Coding Preferences

When working in this workspace, Antigravity MUST adhere to the following rules:

1. **Do not change code unless explicitly instructed to do so.** If the user asks a question, wants to discuss, or does not explicitly say to change the code, do NOT make unprompted changes to the codebase.
2. **Never destroy working logic.** When the user asks to "make something better" or "train" a new feature to improve performance, do NOT overwrite or break the previously working logic. Instead:
   - Build the new logic as a safe addition or a completely separate test first.
   - Wait for explicit user confirmation that the new logic works before replacing the old logic.
